 AI College Helpdesk Chatbot
**Project Overview**:

The **AI College Helpdesk Chatbot** is a web-based application developed using **Python** and **Flask** to assist students by providing instant answers to common college-related queries. It offers information such as admissions, courses, fees, placements, facilities, and contact details through an easy-to-use interface.

This project was developed as part of an **AI Internship** to demonstrate the use of Python and web technologies in building an intelligent helpdesk application.

---

## ✨ Features

- 🔐 User-friendly login page
- 🏫 College selection interface
- 💬 AI-powered chatbot for student queries
- 📚 Information about courses and admissions
- 💰 Fee details
- 💼 Placement information
- 🏢 Campus facilities information

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-College-Helpdesk-Chatbot.git
```

### 2. Open the project folder

```bash
cd AI-College-Helpdesk-Chatbot
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open your browser

```
http://127.0.0.1:5000
```
